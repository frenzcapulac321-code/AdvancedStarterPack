# Advanced Starter Pack — Custom Promotions

## Starter units
- Modern Armoured Vehicle
- Mechanized Infantry Vehicle

## Custom promotions

### Assault
- Mounted / Armor / WaterCivilian
- +1 additional attack per turn

### Blitz
- Requires Assault
- Mounted / Armor
- +1 Movement

### Tank Hunter
- Mounted / Armor
- +25% Strength vs Armor units

### Breakthrough
- Requires Blitz
- Mounted / Armor
- +20% Strength when attacking

### Reactive Armor
- Armor
- +20% Strength when defending

### Siege Breaker
- Requires Breakthrough
- Mounted / Armor
- +25% Strength vs cities

### Rapid Advance
- Mounted / Armor / WaterCivilian
- +1 Movement

### Amphibious Assault
- Mounted / Armor / WaterCivilian
- Eliminates combat penalty for attacking from the sea

### Veteran Crew
- Mounted / Armor / WaterCivilian
- +15% Strength

## Assault limitation
Unciv's current documented JSON uniques support a fixed number of additional attacks per turn, but not a JSON-only kill-triggered "attack again after destroying an enemy" effect. Therefore Assault uses one additional attack per turn.

The promotion structure and `uniques` system follow Unciv's current modding documentation.
